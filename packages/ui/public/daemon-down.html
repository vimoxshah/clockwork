The daemon isn't running.

This window is a native frame around Clockwork's local daemon, which serves both the interface and the API on 127.0.0.1:4747. Nothing is answering there, so there is nothing to draw — that is what a blank window means.

The app bundle does not contain the daemon. It is installed separately, from source.

Start it

cd your-clockwork-checkout && node packages/daemon/dist/main.js

Or, if you installed the background service: launchctl kickstart -k gui/$(id -u)/com.clockwork.daemon

If it starts and then dies

tail -30 ~/.clockwork/daemon.log.err

A NODE_MODULE_VERSION mismatch there means better-sqlite3 was built against a different Node than the one now running it — switching Node versions after install does that. Re-run pnpm install with the Node you start the daemon with. EADDRINUSE means another daemon already holds the port, which is fine.

Never installed it?

git clone https://github.com/vimoxshah/clockwork && cd clockwork
pnpm install && pnpm build
node packages/daemon/dist/main.js

Needs Node 22 or newer, pnpm, and git.
