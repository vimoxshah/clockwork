Design language

Palette — ink & brass
#0C0E14 ground
#141824 panel
#E8A33D brass
#E9EBF3 ink

Deep ink-blue ground, never pure black. Brass is the brand — horology, not the default AI purple.

Semantic state
#4BC97F done
#5EA7F0 booked
#E05C5C stopped
#E8A33D needs you

State reads at a glance; brass doubles as “needs you” — attention moments are brand moments.

Type

System sans for UI — it's a Mac app.
SF Mono, tabular, for every time · cost · branch

The wordmark: spaced small caps, WORK in brass.

Time is the interface

The primary object is the future run — a booking on a grid, not a row in a table. History and future share one surface.

Trust is visible

Sandbox badge in the composer, policy checks in the timeline, budget meters on every report. Safety is shown, not claimed.

Honest estimates

The capacity band says “estimate” on its face. Keep-awake and slept-through states are loud, never silent.

Needs-you is brass

One pulsing color owns every human-in-the-loop moment — calendar, inbox, menubar. Nothing else pulses.

Reports worth reading

Summary before detail, verdict before transcript, one primary action. A report you act on, not a log you scroll.

Native calm

macOS materials, system type, quiet chrome. The drama belongs to the agents' work, not the app.

Profiles give runs a face

Every run wears its agent persona — a colored chip (Dep Surgeon, Docs Scribe) from composer to report. Delegation reads like assigning a colleague, and @mention makes it typeable.

Your login, your data, your channels

Runs on your own Claude Code login — no API key. Reports go where you live: Telegram, WhatsApp via your gateway, any webhook. Search reaches everything, locally.
