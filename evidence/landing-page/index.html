CLOCKWORK

The calendar where your agents show up for work.

You already pay for a coding agent. It idles 18+ hours a day.

Clockwork lets you book agent jobs on a calendar: pick a time, describe the chore, set a budget. At that hour your own Claude Code runs the job in an isolated sandbox and files a report you can actually read — branch, diffstat, cost, transcript.

  • Recurring chores, gone. Dependency triage every Monday. Flaky-test sweep every Wednesday. Docs drift check every Friday.
  • Trustworthy unattended execution. OS-sandboxed per run, writes locked to its worktree, SSH keys unreadable, hard budget caps, never commits to main.
  • Reports worth reading. What it did, what it skipped and why, what it cost — in your inbox, searchable forever.
  • No new account, no API key. It drives the Claude Code login you already have.
⏾ The honest constraint: jobs run when your machine is awake. Clockwork keeps a laptop awake through booked windows when plugged in and tells you loudly when sleep caused a miss — but if you want true overnight runs, use an always-on machine. We'd rather tell you now than disappoint you at 2am.
